# Binários de Instalação (Downloads)

## 🪟 Windows (Compatível com Windows 11 e Windows 10)
> **Importante para Windows 11:** 
> - A grande maioria dos computadores Windows 11 utiliza processador Intel ou AMD de 64 bits: baixe a versão **x64 (Instalador de Usuário)** recomendada.
> - A versão **ARM64** é exclusivamente para dispositivos com chip ARM (ex: Snapdragon X Elite / Copilot+ PC). Se você tentar abrir o instalador ARM64 em um PC Intel/AMD, o Windows 11 emitirá aviso de aplicativo incompatível.
> - **Aviso do SmartScreen no Windows 11:** Como este é um projeto open-source sem certificado comercial corporativo, o SmartScreen pode exibir *"O Windows protegeu o seu computador"*. Clique em **"Mais informações"** e em seguida em **"Executar assim mesmo"**.
